# Lab Assignment – 5

## Python Functions and Data Mutation

This lab assignment focuses on understanding Python functions, mutable and immutable data types, and basic problem-solving using functions.

## Questions Covered

### Q1. List Mutation

A function `remove_last(lst)` is created to remove the last element from a list. The program checks whether the original list changes after the function call.

### Q2. String Reassignment

A function `change_string(s)` tries to replace the first character of a string with `"X"`. The program checks whether the original string changes.

### Q3. Dictionary Mutation vs Rebinding

Two functions are used:

* `add_entry(d)` adds a new key-value pair to a dictionary.
* `reassign_dict(d)` assigns a new dictionary to the local variable.

The results are compared to understand the difference between mutation and reassignment.

### Q4. Maximum of Two Numbers

A function is created to accept two numbers and return the greater number.

### Q5. Factorial of a Number

A function is created to calculate the factorial of a given integer.

### Q6. Celsius to Fahrenheit

A function is created to convert temperature from Celsius to Fahrenheit using:

```text
F = (C × 9/5) + 32
```
